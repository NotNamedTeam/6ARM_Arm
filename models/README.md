# Модели КОМПАС-3D

Открывайте [главную сборку](ROBOT_controlled.a3d) в КОМПАС-3D v25. При переносе проекта сохраняйте файлы `.a3d` и `.m3d` в этой папке вместе.

| Файлы | Содержание |
| --- | --- |
| `BASE_*` | Основание и поворотная платформа |
| `AXIS1_*`, `AXIS2_*`, `AXIS3_*` | Рычаги и корпуса приводов |
| `WRIST_*`, `GRIPPER_*` | Запястье и реечный захват |
| `MG90S_*`, `MG995_*`, `SERVO_HORN_*` | Упрощённые модели сервоприводов и качалки |
| `SCREW_*`, `NUT_*`, `PIVOT_*`, `STANDOFF_*` | Крепёж и дистанционные детали |
