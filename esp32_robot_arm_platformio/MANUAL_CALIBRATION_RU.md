# Калибровка каждого привода отдельно

**Это необязательный вариант на C++. Сейчас используем Python без загрузки
новой прошивки: `manual_calibration.py`, инструкция `PYTHON_CALIBRATION_RU.md`.**

Основной файл для редактирования: **src/manual_calibration.cpp**.
Текущий профиль PlatformIO по умолчанию: **esp32-manual-calibration**.
Старая Wi-Fi-прошивка и исходные калибровки сохранены в других файлах.

## Что менять в начале файла

- `TEST_JOINT = 1` — выбран второй привод, плечо на GPIO17.
- `targetAngles[]` — целевые абсолютные команды всех шести приводов.
- `MOVE_WINDOW_MS = 1200` — подавать сигнал 1,2 секунды. Это не регулировка скорости.
- `HOLD_AFTER_MOVE = false` — после теста выбранный привод также без сигнала.

| Номер | GPIO | Узел | Начальная команда |
|---|---|---|---|
| 0 | 16 | Основание | 0° |
| 1 | 17 | Плечо | 87° |
| 2 | 5 | Локоть | 75° |
| 3 | 18 | Наклон кисти | 30° |
| 4 | 19 | Поворот кисти, непрерывное вращение | 90 = стоп, НЕ угол |
| 5 | 21 | Захват | 0° |

Эти числа — последние заданные команды, **не новая подтверждённая калибровка**.
Целевые углы не означают, что вал действительно их достиг.

## Как пользоваться

1. Устойчиво подоприте звенья: все невыбранные сервы будут без управляющего
   сигнала. После теста сигнал выбранной сервы также прекратится. Под весом
   рука может опуститься. Не удерживайте пальцами шестерни или оси.
2. Измените `TEST_JOINT` и нужное число в `targetAngles[]`. Сохраните файл.
3. В VS Code выберите задачу **ESP32: загрузить индивидуальную калибровку**.
   Во время перезапуска удержание отсутствует. При запросе введите пароль Linux.
4. Откройте задачу **ESP32: консоль индивидуальной калибровки**.
5. Введите `GO` и Enter. Будет включён только выбранный привод, затем через
   заданное время сигнал отключится. Автоматических повторов и возвратов нет.

После изменения исходника нужно снова собрать и загрузить прошивку.
При загрузке, включении и перезапуске автоматически ничего не двигается:
всегда требуется `GO` или явная команда `S`.

## Можно менять углы без перепрошивки

В консоли, 115200 бод, завершение строки **LF / Newline**:

```text
GO          один тест выбранного в файле привода
OFF         прекратить сигналы всех приводов
STATUS      посмотреть заданные команды и состояния ON/OFF
S 1 85      только плечо: команда 85°, затем автоматическое отключение
S 1 83      только плечо: команда 83°, затем автоматическое отключение
J 2         выбрать локоть, без движения
T 76        задать локтю 76°, без движения
GO          выполнить один тест локтя
```

Значения `S`, `J` и `T` хранятся только в оперативной памяти. Подтверждённые
вами положения перепишите в `targetAngles[]`, чтобы сохранить их в проекте.
Закройте консоль перед следующей загрузкой: один USB-порт нельзя использовать
одновременно для прошивки и монитора. Выход из консоли — **Ctrl+]**.

Для GPIO19 поддерживается только короткая команда скорости 80..100,
нейтраль 90. Вращение ограничено 250 мс, затем отправляется нейтраль и сигнал
снимается; удержание для него не допускается даже при `HOLD_AFTER_MOVE=true`.
Угловую калибровку этого привода без датчика положения выполнить нельзя.

## Ограничения

- Командные диапазоны 0..270 / 0..180 унаследованы из старого проекта, это
  **не проверенные пределы механики**. Не начинайте с крайних углов.
- Программа не устраняет возможную неисправность питания, люфты или
  внутренние колебания сервы. Внешнего PID без датчика положения здесь нет.
- `detach` выключает сигнал, **не напряжение питания**. Некоторые цифровые
  сервы продолжают удерживать последнее положение без сигнала. Если тряска
  сохраняется после `OFF`, поддержите руку и физически отключите питание серв.
- Не запускайте другие старые тестовые программы параллельно с этой консолью.
