# Индивидуальная калибровка на Python

Файл с программой и настройками: **manual_calibration.py** в корне проекта ESP32.
Программа использует установленную на плате проверочную прошивку A/S/STOP.
**Перепрошивка не нужна. PlatformIO Upload для этого файла не используйте.**

## Запуск в VS Code

1. Подоприте все звенья, особенно верхнюю часть: невыбранные сервы будут без
   управляющего сигнала, а после теста отключится и выбранная. Рука может упасть.
2. В начале `manual_calibration.py` измените нужные значения в `TARGET_ANGLES`.
   В `ACTIVE_GPIO` выберите один привод. Сохраните файл — **Ctrl+S**.
3. Меню **Терминал → Запустить задачу → ESP32: Python — калибровка по одному**.
   При необходимости введите пароль Linux. Он нужен для открытия USB-порта;
   затем программа переходит к обычным правам пользователя.
4. В открытой консоли введите **GO** и Enter. Настройки перечитаются из файла,
   включится только выбранная серва на `MOVE_SECONDS`, затем все сигналы OFF.
5. Измените угол в редакторе, Ctrl+S, снова GO. Перезапуск Python и загрузка
   прошивки не нужны. Без GO сохранение файла **ничего не двигает**.

Выбрано плечо: `ACTIVE_GPIO = 17`. Целевой угол берётся из вашей записи
`TARGET_ANGLES[17]`, а не из этой инструкции. Это команды, не измеренные углы.

Можно также нажать **Run Python File / ▶** у открытого `manual_calibration.py`.
Если не хватает прав USB, программа сама запросит пароль Linux в терминале.
Она не меняет системные группы и правила USB; после открытия порта работает
с обычными правами. При запуске через панель Output/Debug Console ввод пароля
невозможен — используйте именно терминал или указанную задачу.

Python 3.14, pyserial 3.5 и расширения Python/Pylance/debugpy уже доступны.
Зависимость указана в `requirements-calibration.txt`. Для новых терминалов
проекта настроен Python из рабочего окружения. В панели Testing настроены
только программные unittest: они не открывают USB и не двигают робота.

## Настройки

| Настройка | Назначение |
|---|---|
| `TARGET_ANGLES` | Целевые абсолютные команды по номерам GPIO |
| `ACTIVE_GPIO` | Один проверяемый привод |
| `MOVE_SECONDS` | Время подачи сигнала: от 0,1 до 3 секунд, по умолчанию 1,2 |
| `HOLD_AFTER_MOVE = False` | После теста снять сигнал выбранной сервы |

Сохранённые соответствия: GPIO16 — основание, GPIO17 — плечо, GPIO5 — локоть,
GPIO18 — наклон кисти, GPIO19 — непрерывный поворот, GPIO21 — захват.
GPIO19 оставляйте 90: это нейтраль, не угол. Его вращение здесь заблокировано,
поскольку установленная прошивка не гарантирует остановку при потере USB-связи.

Если вручную установить `HOLD_AFTER_MOVE = True`, только выбранная серва будет
удерживать положение до OFF, следующего GO или выхода. Остальные не включатся.
При нынешней тряске оставьте **False**.

## Команды консоли

```text
GO          взять настройки из файла и выполнить один тест
S 17 85     один тест GPIO17 с абсолютной командой 85°
S 5 76      один тест GPIO5 с абсолютной командой 76°
OFF         снять управляющие сигналы всех серв
STATUS      показать заданные команды, НЕ измеренные углы
Q           закончить программу, снять сигналы и закрыть USB
```

В команде S указывается **GPIO**, не порядковый номер привода.
S не сохраняет число в исходнике: подтверждённые вами значения запишите
в `TARGET_ANGLES`. Ctrl+C прерывает тест и отправляет OFF.

## Важно

- Сначала подоприте звенья. Не зажимайте пальцами шестерни или оси.
- Первый реальный поворот неизвестен, если до команды серва была без сигнала.
  Программа задаёт абсолютный угол, не гарантирует смещение от текущего.
- Диапазоны команд 0..270 для основания и 0..180 для других приводов унаследованы
  из проекта, но не являются проверенными пределами собранной механики.
- Таймер отключения работает на компьютере, пока есть USB-связь. При зависании
  компьютера/обрыве USB автоотключение не гарантируется: поддержите руку и
  физически выключите питание серв. GPIO19 поэтому не запускается.
- OFF снимает сигнал, **не напряжение питания**. Некоторые цифровые сервы могут
  продолжать удерживать положение без сигнала. Если после OFF тряска сохраняется,
  нужно физически отключить питание серв.
- Не открывайте одновременно Serial Monitor PlatformIO и старые тесты:
  один USB-порт должен использоваться только этой программой.
- Проверка настроек без USB доступна задачей **ESP32: Python — проверить настройки
  (БЕЗ робота)**. Она никогда не открывает порт и не отправляет команды.
