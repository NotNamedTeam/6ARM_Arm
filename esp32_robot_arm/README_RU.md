# Управление 3D-печатной рукой через ESP32 и Wi‑Fi

Комплект подготовлен для робота из статьи Instructables: шесть обычных сервоприводов вместо Arduino Mega подключаются к классической плате ESP32 DevKit/WROOM. Управление открывается в браузере телефона или компьютера.

## Что уже скачано

- Arduino CLI 1.5.1 — локально, без изменения системы.
- Пакет плат `esp32:esp32`.
- Библиотека `ESP32Servo` 3.2.1.
- Готовая прошивка `RobotArmWiFi/RobotArmWiFi.ino`.

## Подключение сигналов

| Узел | GPIO ESP32 |
|---|---:|
| Основание | 13 |
| Плечо | 14 |
| Локоть | 16 |
| Наклон кисти | 17 |
| Поворот кисти | 18 |
| Захват | 19 |

Это начальная схема для ESP32 DevKit/WROOM. Для ESP32-S3, C3, WROVER или другой платы распиновку нужно проверить до подключения.

## Важно: питание

Нельзя питать сервоприводы от вывода 5 V или 3,3 V платы ESP32. Используйте отдельный стабилизированный источник 5–6 V, рассчитанный на суммарный ток всех сервоприводов. Землю источника сервоприводов обязательно соедините с GND ESP32. Перед первым включением разгрузите руку и будьте готовы отключить силовое питание.

Сигнальная схема каждого сервопривода:

- сигнальный провод → соответствующий GPIO;
- плюс питания → отдельный источник 5–6 V;
- минус питания → минус источника и GND ESP32.

## После прошивки

1. ESP32 создаёт сеть `RobotArm-ESP32`.
2. Пароль: `robotarm32`.
3. Откройте `http://192.168.4.1`.
4. Приводы при старте выключены. Убедитесь, что рука находится в безопасном положении, затем нажмите «Включить».

Для подключения ESP32 к домашнему Wi‑Fi впишите имя сети и пароль в `WIFI_SSID` и `WIFI_PASSWORD` в начале прошивки. Если подключение не удастся за 15 секунд, плата снова создаст собственную сеть.

## Сборка и загрузка из терминала

Из корня этой папки проекта:

```bash
../../work/toolchain/bin/arduino-cli compile \
  --config-file ../../work/toolchain/arduino-cli.yaml \
  --fqbn esp32:esp32:esp32 RobotArmWiFi
```

После подключения платы узнайте имя порта:

```bash
../../work/toolchain/bin/arduino-cli board list \
  --config-file ../../work/toolchain/arduino-cli.yaml
```

Загрузка (замените `/dev/ttyUSB0`, если показан другой порт):

```bash
../../work/toolchain/bin/arduino-cli upload \
  --config-file ../../work/toolchain/arduino-cli.yaml \
  --fqbn esp32:esp32:esp32 -p /dev/ttyUSB0 RobotArmWiFi
```

Если доступ к порту запрещён, пользователя обычно нужно добавить в группу `dialout`, затем выйти и войти в систему. Эта операция меняет системные настройки, поэтому автоматически она не выполнялась.

## Перед первым движением

- Уточните точную модель ESP32 и номинал блока питания.
- Проверьте, что механические нулевые положения совпадают с начальными углами в массиве `angles`.
- Для каждого сочленения задайте безопасные пределы вместо полного диапазона 0–180°, если механика не допускает полный ход.
- Сначала испытывайте по одному сервоприводу без нагрузки.
